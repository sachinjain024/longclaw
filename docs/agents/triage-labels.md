# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the label slugs used by LongClaw.

| Label in mattpocock/skills | Label in LongClaw | Meaning                                  |
| -------------------------- | ----------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`    | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`      | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent` | Fully specified, ready for an agent      |
| `ready-for-human`          | `ready-for-human` | Requires human implementation            |
| `wontfix`                  | `wont-fix`        | Will not be actioned                     |

When a skill mentions a canonical role, use its corresponding LongClaw label slug.

Additional project labels may be added later without changing this canonical mapping.
