# Pilot session index

This directory holds only redacted public summaries for Step 9 pilot sessions.
Raw notes, recordings, private repository names, logs, and unredacted file
excerpts stay outside the public repository.

## Naming

Use participant codes and dates:

```text
YYYY-MM-DD-P01.md
YYYY-MM-DD-P02.md
```

Do not encode a participant name, company, repository name, or agent account in
the filename.
