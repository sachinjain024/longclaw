A GitHub star control: five places it could stand

The ticket settles that the control lives in the app chrome and carries a live count. It does not settle where, and the five candidates cost very different amounts. Each scene is the app's own markup and styles, so what is on screen is what would ship.

The no-count state is the default everywhere, and the driver starts with it. A count that has not arrived — first paint, offline, behind a proxy, rate-limited at 60 requests an hour per IP — draws no number, no placeholder and no spinner, following ADR 0014's own rule that a failed check claims nothing.

The count is real. The page asks api.github.com for sachinjain024/longclaw's actual star count and fills it in a beat after first paint, which is the designed behaviour demonstrated rather than described. The chip in the driver says what GitHub answered. The page's own fetch is not the proposal: the app's webview has no network capability, so in the app the webview names an intent and Rust decides the host, makes the request and caches the answer.

Two shapes are on the table. pill is the reference shape — a solid near-black lozenge carrying GitHub's mark and the count and no words, optionally with a trailing outline star — and it is what the driver opens on. labelled ghost is the quieter bordered control with Star on GitHub spelled out. The pill is the shape a reader has already learned elsewhere; the ghost is the one that never needs its accessible name to carry the whole meaning, and never needs a fallback word when the count is withheld. Switch between them in every scene.

Read the chip before reviewing anything else. At the repository's count today the number is small enough to argue against the control it decorates, which is why this prototype proposes a floor: the count is drawn at or above 50 and the control is the no-count state below it. That gives the no-count state a second job — not only what offline looks like, but what a young repository looks like — and it costs nothing, because that state has to be designed and legible either way. The three count buttons let you review all of it: no number, the live number, and the number this repository will have later.
