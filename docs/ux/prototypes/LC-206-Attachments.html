Attachments: adding, showing and removing a ticket's files

A human can attach a screenshot, a recording or a log to a ticket wherever they write about it: paste it (⌘V), drop it, or press the paperclip in the description editor or the comment composer. It shows up where it was written about: an image inline, a video as a player, a text file as a chip. Every file on the ticket, and every doc its description links to, is listed in a new collapsible References section of the panel. Removing a file unregisters it and keeps the file. Agents get longclaw ticket attach. Spec: docs/specs/LC-206-attachments.md.
