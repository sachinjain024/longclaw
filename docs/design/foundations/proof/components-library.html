## longclaw · design foundations

One canvas. Two actors. Files on disk.

Every component below consumes only --lc-* tokens. Switch the theme or appearance above: layout never moves, only tokens swap. Human accent means a person planned it; agent green means an agent did it — and green appears nowhere else.

## 02 · color

Two actors, two hues

Indigo — or the active theme's human accent — means a person planned it; green means an agent did it. The app is neutral ink on paper; accents appear only where an actor acted. Values below are read live from the rendered tokens — switch theme or appearance and watch them change (neutrals, status, feedback and labels won't: they are system tokens).

Accents — theme tokens (the only per-theme values)

Derived accent variants — color-mix derivations, never authored per theme

Neutrals — system, theme-independent

Status — system; Done routes to the human accent (completion is a human call)

Priority & feedback — system

Label ramp — 8 fixed hues; the green band is deliberately absent

## 07 · status

A color dot + text

One dot geometry for every status, user-created ones included: the default state is the unfilled grey ring (Todo), every other state fills the same dot with the status color. Done takes the human accent — completion is a human call, and green is never offered. The dot never appears without its label; on the board the column header names it.

## 08 · priority

Scannable, not loud

Six levels, monochrome except Urgent. P1–P4 are bordered mono chips — the number carries the level, so there is no fill hierarchy to read. Urgent and None keep the reference glyphs.

## 09 · avatars

Humans are circles, agents are not

Human tints hash into the label ramp — which contains no green, so no human can ever wear the agent's color. The agent is a terminal tile: near-black in both appearances, mono ❯, agent-green ring. Never in the assignee slot.

## 10 · checklist

Humans write items; agents check them off during execution. A settled check is quiet gray; a fresh agent check wears green with the row wash and a mono timestamp, then settles once the ticket is viewed.
