## Requirements

<div class="callout callout--note">
  <p class="mono">macOS 13 or later · Apple Silicon (M1 or newer)</p>
</div>

There is no Intel or universal binary in this release, and no Windows or Linux
build.

## Download

**[Download LongClaw_0.1.0_aarch64.dmg](https://longclaw.io/downloads/LongClaw_0.1.0_aarch64.dmg)**
— 5.0 MB. Open it and drag LongClaw into Applications.

To check you got what we published, compare the checksum:

```sh
shasum -a 256 ~/Downloads/LongClaw_0.1.0_aarch64.dmg
# a2b8786b53d8b57d44e6bef7f94f4454c49064d8d43584b5b7680ecc1d7800df
```

The same build is attached to the
[v0.1.0 release](https://github.com/sachinjain024/longclaw/releases/tag/v0.1.0)
on GitHub, with the release notes and source.

If you would rather not run a binary someone else built, the repository is the
same code — see [building from source](#building-from-source) below.

## Opening the app the first time

LongClaw is signed with an Apple Developer ID certificate and notarized by
Apple. **Expect one dialog, and expect to click through it once.**

Anything you download from a browser is quarantined by macOS and earns a
confirmation on first launch however good its signature. What notarization
changes is which confirmation. You will see:

<div class="callout callout--note">
  <p>"LongClaw" is an app downloaded from the internet. Are you sure you want to open it?</p>
  <p class="mono">As of <em>the date it was notarized</em>, Apple checked it for malicious software and none was detected.</p>
</div>

Click **Open**. That is the whole step — no System Settings, nothing to
authenticate, and macOS does not ask again for this copy of the app.

That second sentence is read from a ticket stapled into the app itself, so it
appears whether or not you are online. Nothing has to reach Apple for a first
launch to work.

### If you see something else

Two other messages exist, and neither should appear for this build. Both mean
the copy you have is not the one published here.

<Callout tone="warning">
  <p><strong>"Apple could not verify…is free of malware"</strong>, offering <em>Move to Bin</em> — an unsigned or unnotarized build.</p>
  <p><strong>"LongClaw is damaged and can't be opened"</strong>, offering only <em>Move to Bin</em> — a bundle whose signature does not verify.</p>
</Callout>

Download it again from this page rather than working around it, and never strip
the quarantine attribute to get past either one: that turns the check off for
the single app you were least able to vouch for. If you build from source, the
bar is `codesign --verify --deep --strict` passing.

## Point it at a folder

Launch LongClaw and choose any folder — a git repo or an empty directory. It
creates `.longclaw/` inside it and writes nowhere else.

<FileTree lines={[
  { name: 'your-project/', muted: true },
  { rule: '└── ', name: '.longclaw/' },
  { rule: '    ├── ', name: 'longclaw.yaml', note: 'project identity, people, labels' },
  { rule: '    ├── ', name: 'AGENTS.md', note: 'the editing contract agents read' },
  { rule: '    └── ', name: 'tickets/' },
]} />

Point it at the same folder as your code. The tickets then live beside the work
they describe, which is what lets an agent read a ticket and the code it refers
to in one place.

**The project key** — the `LC` in `LC-1` — prefixes every ticket. Pick it when
you create the project; it becomes permanent once the first ticket exists,
because changing it would rename every ticket and every directory.

## Building from source

The desktop app lives in `apps/desktop` and targets Tauri v2 on macOS. You need
Node.js 22 or newer, Rust with Cargo, and the Tauri v2 macOS prerequisites.

```sh
git clone https://github.com/sachinjain024/longclaw.git
cd longclaw
npm --prefix apps/desktop ci
npm run build:app
```
