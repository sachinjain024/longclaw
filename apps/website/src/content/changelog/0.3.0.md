title: The status bar
date: 2026-09-22
limitations: "Projects past the ninth have no ⌘ chord · the star count is drawn only at 50 stars and above, so today the control is the mark alone · there is still no Skip this version · everything 0.2.0 listed still applies."

- Keep the project numbers you have in your fingers. `⌘1`–`⌘9` is a project's
  place in the sidebar, and that place is now stored rather than worked out
  from the name — so a new project joins the list last instead of landing
  wherever it sorts and pushing everything below it along.
- Rename a project without renumbering the rest. Starring, unstarring and an
  unreachable folder move nothing either. Removing a project closes the gap,
  which is the only thing that renumbers now.
- Drag a project row to where you want it, or move it with `⌥↑` and `⌥↓`. The
  badge and the chord are one map, so a row takes its number with it and every
  row it passed takes its own.
- Hear where it landed. The toast names the new number rather than the new
  neighbour — `Moved Acme to 3 of 7 · ⌘3`, or `· no shortcut` for a row that
  went past the ninth place. `⌘Z` puts it back.
- Find the version along the foot of the window. A status bar is a new region
  of the app, and the version line, the update dot and the `Update` link have
  moved into it out of the side panel's footer.
- Open LongClaw on GitHub from that bar, where you can star it. Hovering names
  the address it will open. Starring happens on GitHub — the app has no account
  and cannot star anything for you.
- See the star count beside the mark, once the repository is past 50 stars.
  Below that, and whenever the number is not to hand, the control is the mark
  alone; that is the ordinary state rather than an error.
- Know what the second request is. Fetching the count is one `GET` to
  LongClaw's own repository, at most once a day, reading one field and
  discarding the rest of the answer. It sends nothing that describes you, your
  machine or your projects, nothing waits on it, and a failure shows nothing.
- Turn both off with one switch. The automatic-check preference in *Settings →
  Updates* governs the star count as well, and is read before either request.
  With no internet at all, every feature behaves the same.
