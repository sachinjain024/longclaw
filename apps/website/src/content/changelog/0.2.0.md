title: The update check
date: 2026-09-20
limitations: "The updater is macOS and Apple Silicon only · there is no Skip this version, so an available update stays announced until it is installed or the check is turned off · everything 0.1.0 listed still applies."
requirements: "macOS 13+ · Apple Silicon"
---

- Find out that a newer LongClaw exists, from *Settings → Updates*. The pane
  names the version you are running, says when it last looked, and has one
  button that looks now.
- Install it in two presses, neither of which happens on your behalf. `Update`
  downloads and verifies; `Restart to update` installs. An archive that does
  not verify against the key every copy of LongClaw carries is discarded rather
  than installed.
- Keep your saves. The restart is refused while a ticket write is still going
  to disk, and says why rather than doing nothing.
- Turn the check off, in that same pane, and nothing is ever requested — the
  preference is read before the request, not after one. Left on, it runs once a
  day and when the app opens, never in a loop and never with a retry.
- See that an update is waiting in two places and only two: a dot and an
  `Update` link at the foot of the side panel, and a dot on the `Updates` row
  in settings. Both say so in words as well as in colour.
- Read what changed before you decide. The pane shows this release's notes,
  from the same file this page is written from.
- Carry on as before when the check fails. Nothing outside that pane changes —
  no badge, no toast, no dialog — and a machine that has never checked looks
  exactly like one that is up to date.
- Know what the request is. It fetches one static file from LongClaw's own
  GitHub release and sends nothing that describes you, your machine, your
  projects or your tickets. Where 0.1.0 said *no network connection*, the
  honest line is now *no information*: with no internet at all, every feature
  behaves the same, and the only thing that does not happen is that check.
- Updating from 0.1.0 is still a download — 0.1.0 has no updater. From this
  release on, the app can offer the next one itself.
