title: The update that installs
date: 2026-09-22
limitations: "A failed install now holds the download in memory until you quit, which is what makes Try Again possible · everything 0.3.0 listed still applies."
requirements: "macOS 13+ · Apple Silicon"
---

- Install the update you were offered. 0.3.0 could find a new LongClaw and
  download it, then answer *The download didn't finish* when you pressed
  *Restart to update*. The download was fine; the archive it arrived in could
  not be unpacked. This one can.
- Update straight from the 0.3.0 you already have. The defect was in the file
  0.3.0 was handed, not in the copy doing the handing, so *Update* then
  *Restart to update* is all it takes — no reinstall, and nothing was left
  behind by the install that failed.
- Press *Try Again* and have something happen. The downloaded bytes used to be
  discarded the moment an install was attempted, so after a failure there was
  nothing left to retry. They are now kept until an install succeeds, and the
  retry reuses them rather than fetching the file twice.
- Read what actually went wrong. Every way an install could fail reported *The
  download didn't finish*, pointing at a network that had done its job. An
  install that fails now says *The update couldn't be installed.*
- Reach the download page from the pane. When the app cannot offer an update it
  offers that page instead, and it named an address that is not a page. It now
  names `longclaw.io`.
