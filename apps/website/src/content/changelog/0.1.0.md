- Create, edit, and organise tickets on a board and a dense list, with a
  keyboard path through the whole lifecycle.
- Turn on ticket properties per project — type, due date, start date and
  estimate, each off until you enable it — and set them from the ticket panel,
  the create surfaces or a ticket's context menu. Turning one off hides it
  without touching the tickets that carry it.
- Type a due date the way you say it — `28 Sep`, `Sep 28, 2026`, `today` — or
  pick it from the calendar; forms that would need a locale to read are
  refused rather than guessed.
- See the due date on every card that has one, with overdue, today and
  approaching called out, and sort the board and the list by it.
- Estimate work on the scale the project picks — t-shirt, Fibonacci or a
  duration like `2h` — and give tickets a type from the project's own values,
  defined the way labels are.
- Search and filter across the project, with a command palette on `⌘K`.
- Watch the project folder, so an edit made by an agent or an editor appears
  without a refresh, attributed to whoever made it.
- Recover visibly from unparseable files, conflicting edits, moved folders, and
  a corrupt project list — always without overwriting your file.
- Five themes across light and dark, following your system appearance.
