title: The command, anywhere
date: 2026-11-20
limitations: "The admin prompt has not been tried on every kind of Mac: if a wrong password shows anything but macOS did not accept an administrator password, please open an issue · the safer update protects the update after this one, since 0.3.1's code installs this one · everything 0.3.1 listed still applies."
requirements: "macOS 13+ · Apple Silicon"
---

- Install the `longclaw` command on a Mac that has never had `/usr/local/bin`.
  The same press tries the plain write first and, only when that is refused,
  asks macOS for an admin password once. Before, the app could only hand over a
  `sudo` line to paste into Terminal.
- Cancel the password sheet and nothing is installed; press *Install* to bring
  it back. A refused password hands over the `sudo` line for whoever
  administers the Mac, and *Try again*.
- Keep any file LongClaw did not put at `/usr/local/bin/longclaw`. That is
  checked again as root after the password, and nothing but the link is ever
  written as root.
- Update without risking the app. The new version is unpacked beside the
  installed one and the two are exchanged in a single step, so an update that
  fails leaves the version you had, still opening. Where `/Applications` needs
  an admin, the update asks for a password once.
- Zoom the window with ⌘+ (or ⌘=), ⌘− and ⌘0, from 50% to 200%, or from the
  *View* menu. The level is remembered the next time the app opens.
