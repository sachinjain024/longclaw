Add Support for viewing .md files. We create documents like Product Specs, Tech Specs, etc. And they are references in the tickets. We’d like to open them within the app itself, rather than sending the user to a different app like VSCode to look at the TechSpec markdown file.

The experience should be that Agent always updates the description box with references to the markdown files it creates and user can click on the markdown files reference and open within the editor and there should be a back button in the header to go back to the Ticket UI.

We will follow the same process
- Write Product Spec docs/plans
- Manual review of Product Spec
- Generate UX Prototype docs/ux
- Manual Review of UX Prototype
- Once Approved, Use /implement skill to implement
- Code Review
- Manual Testing
- Merge to main

The Markdown editor should give an experience like Obsidian where users.
